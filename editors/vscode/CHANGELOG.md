# Changelog

## 0.3.0

- Shown on the Marketplace as ".Gram for VS Code" under the id `dotgram.VSCode`.
- First version: diagnostics, semantic colours, completion, hover, signature help, go to definition (into included
  grammars and the C# host), references, highlights, rename, folding, outline and snippets for `.gram` files, from
  the DotGram language server.
- Grammars written into C# strings: diagnostics, colours painted over the C# document's, hover, go to definition,
  references, highlights and rename inside them.
- The symbols of the notation (`|`, `&`, `*`, `+`, `?`, `..` and the rest) coloured apart from names and keywords in
  the default themes; keywords coloured as keywords rather than as control flow.
