# Computed FIX dispatch, 2026-09-16

## Scope and method

Compare `Fix44` and the new `FixDispatch` in the **same Release assembly** on
Windows x64, .NET 10.0.12. Both retain the existing prefix tables, partitioned
materialization and input-buffer pooling. The alternative uses a 29-line grammar,
a C# tag classifier and generated typed field construction split into groups of
64 tags. Standard length/data pairs or a caller-supplied dictionary select the
binary grammar branch. No numeric FIX tags appear in the grammar.

Three fresh processes per implementation and workload, alternating implementation
order by round. Short workloads use 50000 warmups and 500000 measured iterations;
Groups uses 100 warmups and 1000 iterations; Raw uses 100 warmups and 10000
iterations. Each operation includes the public call, complete enumeration and
input disposal. No builds or tests ran concurrently with these measurements.
Numbers below are medians, not statistical confidence intervals. This is a warm
microbenchmark; cold startup, malformed-input performance and network I/O are not
measured. One-field results varied noticeably between processes; see raw output.

Finance assembly SHA256:
`53772E80BB6C5CE6796A89B474A3B1C6E381B3B49FCD5C1ACE15D1C0EA76C975`.

## Results

| Input / workload | Fix44, us/op | FixDispatch, us/op | Speedup | B/op, old / new |
| --- | ---: | ---: | ---: | ---: |
| Bytes / Tag1 | 0.669 | 0.425 | 1.57x | 432 / 440 |
| Bytes / Tag198 | 0.660 | 0.589 | 1.12x | 432 / 440 |
| Bytes / Order | 3.110 | 1.501 | 2.07x | 1592 / 1600 |
| Bytes / Groups | 611.618 | 370.574 | 1.65x | 169352 / 169360 |
| Bytes / Raw | 49.193 | 36.767 | 1.34x | 67944 / 66808 |
| Characters / Order | 4.368 | 1.733 | 2.52x | 1416 / 1424 |
| String / Order | 5.445 | 1.344 | 4.05x | 1376 / 1296 |

Order contains 15 fields; Groups contains 3011 fields; Raw contains 11 results,
including one 65536-byte data field combined with its length. Tag1 and Tag198
contain one text field each. Allocation is essentially unchanged for ordinary
streaming inputs (+8 bytes per enumeration). Raw saves 1136 bytes and the string
order saves 80 bytes. The largest timing gain is the string order (about 4x).
These measurements compare complete implementations; they do not isolate the
cost of the switch instruction from the smaller grammar and construction path.

## Validation

Core tests: 8215 passed, including 20 computed-switch cases. Finance tests: 3794
passed. Alternative-parser tests compare runtime field types, values and locations
against Fix44 for all 186 message fixtures on string, TextReader, byte-array and
one-byte-chunk Stream inputs. Custom binary pairs cover zero length, embedded
separators, NUL, high bytes, chunk boundaries and independent enumerations.
Malformed syntax and binary pair mismatches are rejected.

C# 8 consumer builds passed for net472, netstandard2.0 and net8.0, including a
computed switch on buffered character/byte inputs. Finance builds passed for
netstandard2.0 and net10.0, with no warnings or errors. Regeneration reproduces
the checked-in files exactly. The original Fix44 grammar remains unchanged.

## Reproduction

```powershell
dotnet build benchmarks/DotGram.Finance.Benchmarks -c Release
$runner = 'benchmarks/DotGram.Finance.Benchmarks/bin/Release/net10.0/DotGram.Finance.Benchmarks.exe'
$assembly = (Resolve-Path 'src/DotGram.Finance/bin/Release/net10.0/DotGram.Finance.dll').Path
& $runner profile $assembly Bytes Order 500000 Fix44
& $runner profile $assembly Bytes Order 500000 FixDispatch
```

Inputs: `Bytes`, `Characters`, `String`. Workloads: `Tag1`, `Tag198`, `Order`,
`Groups`, `Raw`. Repeat each pair in three rounds, reversing parser order in the
second round. [Raw measurements](2026-09-16-dispatch-raw.txt).
