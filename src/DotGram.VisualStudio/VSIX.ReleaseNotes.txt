DotGram language support

Initial preview for Visual Studio 18.

- Syntax classification and diagnostics for standalone .gram files and embedded grammars.
- Completion, signature help, Quick Info, brace matching, and folding.
- Go To Definition, Find References, reference highlighting, and Rename.
- Navigation between grammar publications and generated C# APIs.
- Generated DSL discovery through `StringSyntax` language ids and parser APIs.
- Semantic classification, diagnostics, completion, and Quick Info inside DSL strings.
- Versioned referenced-assembly descriptors with classification and non-executing
  guard/external-recognizer contracts.
- The `@` C# transition marker now uses the theme's keyword color.
- The `~` no-trivia sequence operator is classified and described in Quick Info.
- Case-insensitive string and character literals use a distinct theme-derived style.
- Large embedded grammars receive syntax colors before deferred semantic analysis.
- A question mark after a rule name is recognized as the rule gives-back marker.
- Invalid case-insensitive character-set bounds receive precise suffix diagnostics.
- Standalone grammar analysis is debounced and runs off the UI thread for responsive editing of large files.
- Attribute discovery and grammar syntax are synchronized with the current DotGram language version.
- Parameters annotated with `StringSyntax("DotGram")` or `StringSyntax(".gram")`
  enable DotGram grammar tooling.
- A host has one `[Gram]`; additional `[GramOptions]` readings no longer look like
  separate grammar sources to editor tooling.
- File names in `[Gram("Language.gram")]` are no longer analyzed as embedded grammar text.
- Standalone and embedded grammars are analyzed with direct and transitive
  `[GramInclude]` grammars, including aliases declared with `As`.
- Standalone diagnostics and colors refresh immediately when included project context
  becomes available, without requiring the editor viewport to be scrolled.
- Included-grammar context resolution waits for Roslyn project loading instead of permanently
  accepting the incomplete workspace visible during early document restoration.
- Go To Definition and Ctrl+Click open included grammar files from namespace qualifiers,
  and file-valued `[Gram("Language.gram")]` arguments navigate to their additional files.
- DSL `StringSyntax` annotations also work on extension receivers and immediate field
  or property initializers.
- Provisional analysis preserves existing colors while a line edit is being analyzed.
- C# symbol navigation prefers exact members and can find matching references in
  standalone grammar C# expressions.
- Qualified C# member navigation resolves the containing type before falling back to
  a same-named symbol in another type.
- F12 on a C# host member finds its unqualified use in that host's standalone grammar.
- Find All References from C# combines Roslyn references with exact references in
  standalone grammar C# expressions.
- Find All References from C# also includes C# expressions in embedded grammars.
- Embedded grammar colors are re-applied immediately after editor changes while
  semantic analysis continues in the background.
- Standalone grammar edits retain translated colors while parsing runs off the UI
  thread, and file-valued `[Gram]` arguments remain ordinary C# strings.
