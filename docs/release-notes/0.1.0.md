# DotGram 0.1.0

The first release of DotGram: a source generator that compiles `.gram` grammars into
typed C# parsers during the build, libraries of ready-to-use parsers, and Visual Studio
language support.

## Packages

- **DotGram** generates parsers with typed captures, grammar specialization, streaming
  over `TextReader`, lexical tokenization, recovery and grammar libraries across project
  references. Generated parsers need no DotGram runtime assembly. The generator requires
  Roslyn 4.14 or newer.
- **DotGram.Sql** provides SQL:2023, SQL-92 and T-SQL parsers. SQL:2023 has a typed tree
  and writer in `DotGram.Sql.Ast`; SQL-92 and T-SQL share the separate `DotGram.Sql` tree,
  writer and walker. T-SQL entry points cover compatibility levels 100 through 170.
- **DotGram.Web** reads JSON, JSON Pointer and Patch, HTTP headers, URIs and URI templates,
  email addresses, timestamps and language tags through public value types with parsing APIs.
- **DotGram.Finance** reads FIX 4.4 messages with typed values, strict and lenient validation,
  nested repeating groups, raw data and vendor length/data pairs.
- **DotGram.ExpressionLanguage** parses a C#-style expression language directly into
  `System.Linq.Expressions` trees.

The four parser libraries target `netstandard2.0` and `net10.0`. Their only package
dependency is `System.Memory` on `netstandard2.0`.

## Visual Studio

The extension targets Visual Studio 2022 17.14 and Visual Studio 18 on x64. It provides
highlighting, diagnostics, completion, Quick Info, navigation, references and Rename for
standalone and embedded grammars, plus tooling for `StringSyntax` DSL strings.
