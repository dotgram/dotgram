# DotGram 0.1.1

Maintenance release following 0.1.0.

## Generator

- Guards over repeated text captures receive all retained pieces, in input order,
  rather than only the last piece. Separators outside the capture are not included,
  and backtracking removes abandoned pieces.
- Optional groups beside guards compile correctly with the Immediate and Mixed carriers,
  including when Auto selects one of them.
- Integration tests now build a separate grammar library and execute both an included
  grammar and an inherited grammar from its emitted `GramSource` metadata.

## ExpressionLanguage

- Type, namespace and extension-method lookup uses the caller's assembly and its transitive
  runtime references, respecting .NET assembly load contexts. Unrelated loaded assemblies
  no longer contribute names. Duplicate public full names in references are ambiguous.
- This changes expressions that previously depended on an unrelated assembly already being
  loaded. The reference graph comes from runtime metadata, not the compiler's original
  reference list; unused compiler references may be absent.
- The README documents generic and extension method support and makes clear that expression
  execution is not a sandbox and must not be used for untrusted text.

## Packages and documentation

All five packages share version 0.1.1. The parser libraries are rebuilt with the corrected
generator. The generator's packaged skill includes the Web and Finance catalogue and links
to the matching `v0.1.1` source snapshot. No diagnostic identifiers or severities changed.
